# Company logos

Drop clean logo files in this folder, named **exactly** as listed below.
The site renders them **borderless** on the dark navy background, so each file must be:

- **Transparent background** (PNG or SVG)
- **White or light / monochrome** strongly preferred, so it's visible on the dark page
  (a dark-colored logo will be hard to see — when in doubt, use the white version)
- At least ~240px on the long side (they display ~38px tall, so this keeps them crisp on retina)
